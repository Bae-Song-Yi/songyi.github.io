# 💗 두근(두근메이트) — 프로젝트 소개

## 1. 한 줄 소개
**"혼자 와도, 설렘은 함께."**
직장인이 혼자 신청해도 **AI가 잘 맞는 사람을 찾아 오프라인 그룹 소개팅으로 연결**해주는 매칭 컨시어지 서비스.

## 2. 해결하는 문제
- 소개팅 앱은 많지만 "혼자 나가기 부담 / 상대가 누군지 모르는 불안 / 진지하지 않은 사람"이 문제.
- 두근은 **혼자 신청 → AI 매칭 → 소수 그룹으로 안전하게 오프라인 만남**으로 이 부담을 줄임.

## 3. 핵심 컨셉
- 혼자 신청해도 OK — AI가 **지역 · 활동 시간대 · 만남 취향** 기반으로 매칭
- 신청 시 **고유 숫자코드** 발급 → 소개팅 당일 코드로 자리 찾기 + **AI 추천 대화주제** 제공
- 참가비는 **매칭 성사 시 1만원** (신청 단계에선 지불 의향만 확인)

## 4. 사용자 흐름
1. **랜딩** — 핑크 감성 UI, 좌우 떠다니는 장식, 가운데 휴대폰 목업
2. "신청 시작하기" → 폰이 떠오르며 **대화형 단계 폼** 시작
3. **STEP 0 · 회사 이메일 인증 (게이트)**
   - 회사 이메일 입력 → 6자리 코드 발송 → **3분 내 입력** → 인증
   - gmail · naver 등 **개인 메일 차단** (직장인만 신청)
4. **STEP 1~9** — 성별 / 출생연도 / 활동지역 / 직업 / 만남 취향 / 활동 시간대 / 자기소개 / 프로필 사진(선택) / 카카오톡 ID
5. **완료** — 고유 **숫자코드** 화면 노출
6. (소개팅 당일) 코드 입력 → **AI 대화주제** 받기

## 5. 주요 기능
- 대화형 스텝 신청 폼 (이전 답변이 위로 쌓이는 UX)
- 회사 이메일 OTP 인증 (6자리 · 3분 만료 · 카운트다운)
- 신청 완료 시 숫자코드 발급
- **AI 대화주제 추천** (코드별, Gemini)
- **신청 시 Slack 실시간 알림** (운영자)
- **도움말 챗봇** (FAQ 버튼 + Gemini 자유질문, 모바일 최적화)
- 프로필 사진 업로드 · 개인정보 동의 · 입력값 검증(숫자 전용/출생연도 범위)
- 반응형(모바일·PC) · 두근비트 로고 · 파비콘

## 6. 기술 스택 / 인프라
| 영역 | 사용 기술 |
|------|-----------|
| 프론트엔드 | 순수 HTML / CSS / JS (단일 파일), Pretendard 폰트 |
| 호스팅 | Cloudflare Pages (main 브랜치 자동 배포) |
| 도메인 | **dugeunmate.com** (Cloudflare) |
| 백엔드 | Supabase — Postgres(`applicants`), RLS, RPC(`log_event`), Storage(사진), Edge Functions(Deno) |
| 이메일 | Resend SMTP (도메인 SPF/DKIM/DMARC 인증) → Supabase Auth 연동 |
| AI | Google Gemini (대화주제 · 챗봇) |
| 알림 | Slack Webhook |

### 데이터 (applicants 주요 컬럼)
`session_id, code, email, gender, birth_year, region, job, meet_style, available, intro, kakao_id, wtp, photo_url, utm_source, variant`

### Edge Functions
- `conversation-topics` — 코드 2개의 프로필로 AI 대화주제 생성
- `faq-chat` — 챗봇 자유질문 응답
- `notify-new-applicant` — 신규 신청 Slack 알림
